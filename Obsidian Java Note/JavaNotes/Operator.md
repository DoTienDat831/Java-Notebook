| Toán tử | Ý nghĩa     |             |
| ------- | ----------- | ----------- |
| `+`     | Cộng        |             |
| `-`     | Trừ         |             |
| `*`     | Nhân        |             |
| `/`     | Chia        |             |
| `%`     | Chia lấy dư |             |
| Toán tử | Ví dụ       | Tương đương |
| `=`     | `a = 5`     | Gán 5       |
| `+=`    | `a += 5`    | `a = a + 5` |
| `-=`    | `a -= 5`    | `a = a - 5` |
| `*=`    | `a *= 5`    | `a = a * 5` |
| `/=`    | `a /= 5`    | `a = a / 5` |
| `%=`    | `a %= 5`    | `a = a % 5` |
